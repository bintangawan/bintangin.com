# Mengelola portofolio

Semua konten kartu proyek berada di `projects.js`. Untuk menambah proyek:

1. Simpan thumbnail JPG teroptimasi dengan rasio sekitar 16:10 ke `public/images/projects/`.
2. Salin salah satu object di dalam array `projects`.
3. Ganti `slug`, `title`, `category`, `year`, `description`, `result`, `tech`, `image`, dan `url`.
4. Pastikan nilai `slug` unik dan path `image` diawali `/images/projects/`.

Ukuran yang disarankan adalah lebar 1200 px dengan ukuran file di bawah 100 KB.
